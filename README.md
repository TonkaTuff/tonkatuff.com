# tonkatuff.com

The site at https://tonkatuff.com. One static page, served by GitHub Pages.

Free libraries, no subscription. If one saved you an afternoon, shout me a beer.

## Edit

`index.html` is the whole site. The orbs come from
[ephemeris](https://github.com/TonkaTuff/ephemeris) via jsDelivr.

## DNS

GitHub Pages with a custom domain. At the registrar:

| type | host | value |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | tonkatuff.github.io |

Then in the repo settings, Pages, tick "Enforce HTTPS" once the certificate has issued.
